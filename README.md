# Digital-OptiSpec
Digital Microscopes 

Use v2.00 when upgrading the application:
1. Download the appropriate "DE_Microscope" from this repository and place it in the "Upgrade" folder in the root directory of a USB stick.
2. Eject the USB stick and insert it into the microscope's HMI.
3. Insert a USB keyboard into the microscope's HMI and use alt+F4 to close the application and access the desktop.
4. Click the small Domaille Engineering shortcut in the top-left of the screen.
5. Select Yes when prompted to overwrite/upgrade the application.
6. Wait for the application to boot and then disconnect both USB devices.
7. The version of software will be denoted in the bottom-right of the screen in yellow text from v2.00 on.
